**Sistema de Gestão de Condomínios**

Aplicação desenvolvida para auxiliar na administração e comunicação de condomínios.

Principais recursos:

- 👥 Gestão de moradores
- 🏠 Gestão de residências
- 📅 Reservas de espaços
- 📢 Comunicados
- 🚨 Ocorrências
- 💬 Chat privado
- 🌐 Chat geral
- 📖 Regras do condomínio
- 🕐 Horários de serviços
- 🔔 Notificações
- 💰 Controle financeiro
- 👨‍💼 Painel administrativo
- 📱 Interface responsiva para computador e celular

**Tecnologias:**

`React Native` `Expo` `TypeScript` `Supabase` `Vercel`
